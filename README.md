# Python For All

Python For All is a static web app. It can be hosted on GitHub Pages, Netlify, Vercel, or any normal static website host.

## Login

Default password:

```text
python123
```

Change it in `script.js`:

```js
const PASSWORD = "python123";
```

## Host Online

Upload the full contents of this folder:

```text
index.html
style.css
script.js
programs.js
images/
icons/
```

The site does not need a backend server.
